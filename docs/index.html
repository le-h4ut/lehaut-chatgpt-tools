TAKE IT WITH YOU

On Firefox Android?

Add Tampermonkey from Firefox Add-ons, return here, and install Message Search and RP Exporter. No PowerShell needed.

Fixpack is optional and desktop-oriented. Its mobile Markdown behavior is not guaranteed.

Need a hand?

I see JavaScript instead of an install window.

Make sure Tampermonkey is enabled in this browser, allow userscripts if required, then reopen the link. Alternatively, open Tampermonkey → Dashboard → Utilities → Install from URL and paste the script's raw link.

The scripts don't appear in ChatGPT.

Enable the scripts and allow Tampermonkey access to chatgpt.com. Refresh ChatGPT after installation. Disable duplicate copies and older standalone Fixpack components. ChatGPT changes can also break private APIs; check the repository for updates.

I'm on a shared or restricted PC.

If the PC's rules block extensions or GitHub, ask the administrator. This installer does not bypass those restrictions. When leaving, sign out of ChatGPT and remove any private exports you saved.

Where does my data go?

Search and Exporter process your conversation in your browser using your signed-in ChatGPT session. These tools and this page add no analytics. Downloads and updates use GitHub; Fixpack also loads its pinned Markdown library from jsDelivr. Your conversation is not sent to this project. Browser, hosting and extension providers have their own privacy policies.
