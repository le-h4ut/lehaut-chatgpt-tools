# Stable source snapshots

These files are the untouched inputs from the supplied Le_Haut ChatGPT Tools source pack. `SHA256SUMS.txt` records their original byte-level checksums.

Install the canonical files from `../userscripts/`, not these snapshots: archived files have no GitHub update URLs.

The initial distribution deliberately preserves every byte after the userscript metadata header. `scripts/verify.ps1` checks this baseline and preservation of every original metadata directive.
